# T2M v2 改版 Spec（定稿）

> 母票：#1。功能清单定稿自 #4，UI 方向定稿自 #5 原型评审。本文为收口版，实施票以此为唯一依据。

## 1. 定位

纯客户端种子 → 磁力链接工具。现有功能全部保留，只做加法。

## 2. 架构约束（锁死）

- 核心转换（bencode 解析、SHA-1、磁力拼接）始终在浏览器本地完成，种子文件不上传
- 匿名使用为纯客户端；登录（可选）后提供 D1 历史记录服务（现状已实现，不动）
- 纯 HTML/CSS/JS，无框架、无构建步骤、无新增第三方依赖
- Cloudflare Workers 静态托管，离线可用（现有架构不变）

## 3. UI 交互结构（#5 原型定稿）

胜者：**双栏工作台 + 侧滑抽屉详情**（原型见 `prototype/ui-v2` 分支 `public/prototype.html`，变体 B + C 的抽屉）。

### 桌面（>760px）

```
┌─────────────┬──────────────────────────┐
│ 左栏 (340px)│ 右栏                      │
│ · logo/登录 │ · 结果区（常驻，含空态）  │
│ · mini 拖拽 │   - 紧凑行式列表          │
│ · 选择文件  │   - 点击行 → 侧滑抽屉     │
│ · 文件夹    │     展示种子详情 + 全部操作│
│ · 输出选项  │                          │
│ (sticky)    │                          │
└─────────────┴──────────────────────────┘
```

### 移动端（≤760px）

- 顶部页签「转换 / 结果」切换两栏，单屏单栏
- 拖拽不可用，**显式「选择文件」按钮为唯一入口**，触屏目标 ≥48px；文件夹入口隐藏
- 详情抽屉降级为底部弹层（≤82vh，圆角顶角）

### 抽屉内容（种子详情）

name、总大小、文件数、创建日期、文件列表（路径 + 大小）、tracker 列表、info_hash，以及该条的全部操作按钮。

### 关键状态

空态（右栏占位）/ 拖拽中（mini dropzone 高亮 + 文件数预览）/ 解析中（进度条 + n/N）/ 结果（行式列表）/ 错误（行内红色标注，不中断其余结果）。

## 4. 功能清单（#4 定稿）

### P0（本次必做）

| 功能 | 说明 |
|------|------|
| 种子详情展示 | 抽屉内：name、总大小、文件列表、文件数、创建日期、tracker 列表 |
| 公共 tracker 注入 | 左栏勾选项，附加内置 ~20 个公共 tracker 列表 |
| 每条结果单独复制 | 行内按钮；「复制全部」保留 |
| 移动端显式选择入口 | ≥48px 按钮，拖拽仅桌面增强 |

### P1（本次做）

| 功能 | 说明 |
|------|------|
| Web Share 分享按钮 | `navigator.canShare()` 探测后显示；剪贴板始终保留 |
| 一键在客户端打开 | 触发 `magnet:` URI |
| 输出格式选项 | 含/不含 dn、tr；info hash base32/hex |

### 否决（不做，将来有需要再议）

tracker 编辑、创建 .torrent、磁力 QR 码。

### 范围外（确认）

磁力→种子（需服务端）、种子健康查询（CORS）。

### 保留（现状不动）

登录 + D1 历史（含搜索/删除/统计）、视频过滤及过滤摘要、粘贴导入、复制 info hash、复制后缀/正则。
